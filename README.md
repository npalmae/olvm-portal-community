# 🖥️ VIRTUAL-PORTAL

**Portal de administración multitenant para VMware vSphere**

Self-service web para gestionar máquinas virtuales, datastores, ISOs y usuarios
sobre vCenter (vSphere 7.x / 8.x / 9.x), con aislamiento por tenant mediante
vSphere Tags y control de acceso basado en roles.

> Producto derivado del portal OLVM de [sixmanager](https://sixmanager.com).
> Documentación técnica: [`docs/vmware-architecture.md`](docs/vmware-architecture.md) ·
> API: [`docs/API.md`](docs/API.md)
